### `LASU Connect` — the largest active build

A campus-oriented platform for **real-time communication, events and campus channels**. This is currently my most active repository and the build receiving the most attention.

The repository brings together:

- Real-time chat and campus communication
- Events, ticket claims and QR-based entry flows
- Campus channels with posts, follows and voting
- Authentication and protected routes
- Media upload infrastructure
- A frontend experience and an expanding backend system

```text
services     Cloudinary · Resend · Multer
status       actively evolving
```
